This repository contains practical tasks and code examples from the **Java Programming Basics** course. As a manual QA engineer transitioning to test automation, I've used this course to build a strong foundation in Java, which is essential for writing robust automated tests.

## Course Topics Covered

| Lesson | Topic | Description |

| 2 | Installation | Java JDK & IntelliJ IDEA setup |
| 3 | Basic Concepts | Output and program structure |
| 4 | Variables & Data Types | Primitive and reference types |
| 5 | User Input & Math | Scanner, arithmetic operations |
| 6 | Conditional Statements | if-else, switch-case |
| 7 | Loops | for, while, do-while |
| 8 | Arrays | One-dimensional and multidimensional arrays |
| 9 | Collections | Collections Framework (List, Set, Map) |
| 10 | Functions | Methods, parameters, return values |
| 11 | OOP Basics | Object-Oriented Programming concepts |
| 12 | Classes & Objects | Creating classes and objects |
| 13 | Constructors | Class constructors, overloading |
| 14 | Inheritance | extends keyword, parent-child classes |
| 15 | Polymorphism | Method overriding, dynamic binding |
| 16 | Abstract Classes | Abstract classes and methods |
| 17 | Nested Classes | Inner and anonymous classes |
| 18 | Packages & Static | Packages, overloading, static keyword |
| 19 | Interfaces | Interface implementation, multiple inheritance |


## How to Run

### Prerequisites
- Java JDK (version 11 or higher)
- IntelliJ IDEA (or any Java IDE)

### Run in IntelliJ IDEA
1. Clone the repository:
   ```bash
   git clone https://github.com/YevhenTarasenko/java-course-in-ua-youtube.git 
   ```
2. Open the project in IntelliJ IDEA
3. Navigate to any class with a main method
4. Click the green ▶ button to run
